## ⏬ How To Install ⏬
> - Download latest menu
> - Put in your plugins folder
> - Open Gorilla Tag —> Done!
> (Disable your antivirus if you have problems installing)

## 🅱️ How To Stay Unbanned 🅱️ 
> - Use **Anti Report**
> - Don’t be an idiot 
> - Always **update** if there is a new menu update!

## 🖥️ Use Menu On PC 🖥️ 
> - To Use Mods = **PRESS "G" OR "T" ON KEYBOARD**
> - Open Menu = **PRESS `ALT` KEY (CAN CHANGE IN SETTINGS)**
> - To Use Guns = **Enable `Enable guns on pc` in config**

## 🌐 Menu Info 🌐
> - W = Working
> - D = Detected
> - DB = Delay Ban
> - UD = Undetected
> - NW = Not Working
> - WIP = Working Progress
> - CS = Client Sided (only you can see)
> - SS = Server Sided (everyone can see)
> - Pub= Needs To Be In A Public Gtag Lobby
> - Priv = Needs To Be In A Private Gtag Lobby
> - Stump = Needs To Be in Stump/Near A Computer
> - MS = Mod Sided (people with same mod can see)
> - M = Master Client (needs to be on top of leaderbord)
> - OWNER SHIP = You Need To Be The Latest One That Touched/Grabed (for example dug the bug)
